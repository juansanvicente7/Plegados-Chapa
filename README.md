# Plegados

Planificador de corte y plegado de chapa para zinguería. Funciona 100% en el navegador, sin servidor ni base de datos.

- Cargá cada corte por tramos (longitud + ángulo de pliegue) y velo en perfil acotado e isométrica.
- Optimiza la distribución de las piezas en la chapa (1,22 × 2,44 m o 1,00 × 2,00 m) con cortes de guillotina.
- Genera el plano PDF para el chapista: esquema de cada chapa + isométrica y perfil de cada corte.
- Cotas de plegado directo, sin descuento. Pestaña mínima 10 mm · plegado máximo 3 m.

## Uso

Abrí `index.html` en cualquier navegador, o visitá la versión publicada con GitHub Pages.

En iPhone/iPad: abrir en Safari → Compartir → **Agregar a pantalla de inicio**.

Los trabajos se guardan automáticamente en el navegador. Usá **Exportar/Importar** para archivar cada obra como `.json`.
